Overview

Purpose

ShelfWatch helps readers who follow book series keep track of upcoming release dates in one place. The site lets a user add books they're waiting on, automatically flags books once their release date has passed, and surfaces "coming soon" and "still unannounced" titles so nothing slips through the cracks.

Audience

The primary audience is avid readers, especially fans of ongoing book series (fantasy, sci-fi, etc.) who want a simple way to remember when the next book in a series comes out without repeatedly searching for release news themselves.

Dynamic elements

JavaScript powers nearly everything on the page beyond the static layout:

  • Objects: each book is stored as an object (title, author, series, releaseDate, status, coverUrl, acknowledged).
  • Arrays + array methods: all books live in one array. filter() splits that array into "released," "coming soon," and "date unknown" groups; forEach() builds a card in the DOM for each book in a group.
  • DOM interaction: a form listens for a submit event to add a new book; "Got it" buttons on alert cards listen for click events to dismiss an alert; a search field listens for input events to trigger the Google Books autofill dropdown.
  • Conditional branching: when a book is added or rechecked, an if/else chain decides its status — released (today's date is on/after the release date), coming soon (release date is within 30 days), or unknown (no confirmed date yet, so it gets queued for periodic rechecking).
  • Fetch/API call: a call to the Google Books API (https://www.googleapis.com/books/v1/volumes?q=) returns matching titles so the user can pick one and auto-fill author, cover image, and (if available) publish date. The user can still edit any field by hand before saving. Books saved with an unknown release date get rechecked against the API periodically (on a timer and via a manual "Check now" button) until a real date appears.
  • Storage: the book array is saved to localStorage so the list persists between visits.

Pseudocode for your project

  1. On page load, read the saved book array from localStorage (or start with an empty array).
  2. Define a renderCards(books) function that:
    • uses filter() to split books into released, coming-soon, and unknown-date groups
    • uses forEach() on each group to build and insert a card element into the matching section of the DOM
  3. Define a getStatus(book) function that:
    • if book.releaseDate is unknown, return "checking"
    • else if today's date is on/after releaseDate, return "released"
    • else if releaseDate is within 30 days, return "coming soon"
    • else return "upcoming"
  4. Listen for the search input's input event, and on each keystroke (debounced) call fetchBookMatches(query), which fetches from the Google Books API and fills a dropdown of matching titles.
  5. When the user picks a dropdown match, auto-fill the author, cover image URL, and release date fields (if the API provided them), while leaving all fields editable.
  6. Listen for the add-book form's submit event. Prevent the default page reload, build a new book object from the form fields, run it through getStatus(), push it into the books array, save the array to localStorage, and call renderCards() again.
  7. Define a checkPendingReleases() function that filters the books array for status "checking," re-queries the Google Books API for each, and updates the object (and re-renders) if a real release date is now available. Run this function on a timer and also on a manual "Check now" button click.
  8. Listen for clicks on each card's "Got it" button; set that book's acknowledged property to true, save to localStorage, and re-render so the alert styling disappears.
